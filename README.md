# CodeAlpha_EmotionRecognition
## Overview

This project is an Emotion Recognition from Speech system developed as part of the CodeAlpha Machine Learning Internship.

The system analyzes speech audio and predicts the corresponding human emotion using a deep learning model.

## Features

- Speech audio input
- Audio preprocessing
- Emotion prediction
- Interactive Streamlit interface

## Technologies

- Python
- TensorFlow
- Scikit-learn
- Librosa
- Streamlit
- NumPy
- Pandas

## Dataset

The project uses the RAVDESS speech emotion dataset.

## Machine Learning

A deep learning model is used to classify emotions from speech features.

## Streamlit Application

The project includes an interactive Streamlit web application for emotion prediction.
